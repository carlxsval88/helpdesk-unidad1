# Sistema de Gestión de Incidentes Help Desk - Unidad 1

Este repositorio contiene la documentación del diseño arquitectónico lógico de un sistema de gestión de incidentes Help Desk para un Data Center.

## Contenido del proyecto

- Análisis del problema
- Identificación de actores
- Requerimientos funcionales
- Requerimientos no funcionales
- Diagramas UML
- Patrones de diseño aplicados
- Gestión de versiones mediante Gitflow
